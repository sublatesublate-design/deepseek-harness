# Agent Note: 感知会话状态的 DeepSeek 蓝鲸宠物

Status: implemented

[English](2026-08-14-deepseek-whale-pet.md) | 中文

## 问题

DeepSeek Harness 会在浏览器客户端公开 agent 的运行、等待、失败和完成生命周期，但应用缺少一个能够跨对话与详情界面持续显示的紧凑环境指示器。复用安装在 Codex 中的宠物，会使 Harness 功能依赖另一个产品的私有文件系统和运行状态；与 Harness 事实脱节的装饰性动画则会错误报告活动。

## 决策

**蓝鲸是 Harness 客户端插件。** `@deepseek-ai/dsh-client-ui-pet` 提供一个可叠加的 `shell.overlay` 条目，因此 Web 与 Desktop profile 共用同一组件，无需新增 React root，也无需修改布局所有者。Web bundle 显式组合该包；移除对应图条目即可移除该功能。

**Harness 会话状态持有任务动画。** 根级条目投影当前会话的 conversation observable，并与选中会话的 summary 组合。失败优先于阻塞中的审批或提问，后者优先于活动工作。从运行切换为空闲时，会先执行一个时长受限的检查动作，再进入普通空闲。这些状态优先于问候、点击和指针动作，因此宠物不会隐藏任务状态。

**本地动作使用其余 sprite-version-2 行。** 首次挂载时挥手，空闲时点击会跳跃，拖动时根据水平移动方向使用左行或右行。附近指针会选择十六个顺时针 look cell 之一；方向索引以向上为零，并按 22.5 度递增。该控件可通过键盘聚焦、使用本地化文本、限制在 viewport 内，并在减少动态效果偏好下保持静止。

**桌面移动使用受限的 preload 桥接。** 透明桌宠窗口让蓝鲸按钮保留正常的指针事件路径，拖动期间通过 Electron 主进程移动原生窗口。`petOnly` 文档会把共享 overlay slot 过滤为蓝鲸条目；桌面专用的 `BroadcastChannel` 会先把主 renderer 的当前会话选择同步到桌宠 renderer，再由桌宠 renderer 消费自己的实时会话流。桌宠加载失败时会销毁该窗口，后续切换可以重试。动态气泡使用带参数的 locale key，不再硬编码特定语言的前缀；高频 reasoning 块只解析为稳定的思考状态，不显示模型内部文本，工具目标和回答尾部保持长度受限。

**经过验证的图集随插件 bundle 发布。** 该包持有 8×11 WebP 源文件。共享客户端 bundle 预设会把导入的 PNG 与 WebP 资源转换为受 watch 的 data-URL 模块，使动态获取的插件保持自包含，而无需增加应用级全局静态路由。

## 曾考虑的替代方案

**通过 Codex 安装或读取宠物。** 不采用：DeepSeek Harness 不应依赖另一个产品的用户配置、renderer 或私有宠物目录。

**直接从 Web 应用入口渲染蓝鲸。** 不采用：入口是启动 kernel，产品 UI 应位于可移除插件中，而布局已经提供可叠加的 `shell.overlay` slot。

**仅根据指针交互播放动画。** 不采用：如果 agent 等待审批或失败时吉祥物仍继续玩耍，它就会失去持续显示所应提供的状态价值。

**从仅限 Web 的 public 目录提供图集。** 不采用：插件会失去自包含特性，替代组合也需要一条未记录的配套静态路由。内联光栅模块会增加获取的插件 bundle 大小，但保留单一产物及 loader 生命周期。

## 后果

默认 Web 与 Desktop profile 会显示一只 DeepSeek 蓝鲸，覆盖全部九种标准动画状态和十六个观察方向。其状态跟随当前选中的 Harness 会话，拖动、点击和桌宠原生窗口移动均不对模型可见。由于经过验证的图集使用 base64 编码，该插件会为未压缩客户端 bundle 增加约两兆字节；它不会增加 Host RPC、会话事件、提示词内容或持久格式。宠物选择、显示设置、位置持久化、替代图集注册和包级资源分块保留为可扩展能力，而不是隐藏默认值。
