# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | 中文

Web 设置中的**插件列表**标签页。浏览器插件注册一个 id 为 `all` 的本地化 `settings.plugins.tab` 贡献；“插件”分区拥有导航入口与标签栏。插件激活期间不会读取 Remote；首次选择该标签页时才挂载组件，并通过 [`api-remotes`](../../api/remotes/README.md) 懒调用 `ctx.remote.pluginInventory.list()`。

该标签页首先说明部署信任规则：插件在 Harness 进程中运行，拥有该进程的文件、网络与进程权限，故障隔离并非安全沙箱。随后以可搜索的双列紧凑折叠卡片展示清单。每张收起的卡片使用模块短名称作为标题，以小标签表示有效启停状态；已启用的条目还会以彩色圆点表示生命周期。展开卡片后会展示 Loader 树条目 id、有效配置状态、Cordis 状态与失败策略。显式隔离的失败还会显示 Host 提供的长度受限诊断与重试操作；重试成功后原位替换该行，失败时只显示通用错误并引导查看 Host 日志。普通的明确失败行不提供修改控件。加载、空结果、无匹配结果与通用读取失败状态只属于已挂载组件。注册使用 `ctx.slots.inject()`，因此能跟随标签 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

## 模型体验

无，因为本包只在浏览器设置中展示 Host 拥有的部署快照，不注册任何模型接口。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **每次 Settings 挂载或列表重试只读取一份快照** —— 标签页不订阅 Loader 变化，也不会在重连后自动重新读取；隔离插件重试只更新该行。
- **恢复能力范围窄** —— 标签页不能启用、停用、添加、删除或重新配置插件；只有失败的显式边界提供重试。
- **无来源信息** —— 本地搜索不会按来源分组，也不解释条目由哪个 bundle、profile 或 override 引入。
